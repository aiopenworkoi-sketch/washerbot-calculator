# WasherBot — калькулятор окупаемости робот-мойки

Финансовая модель роботизированной автомойки Leisuwash: окупаемость, NPV, IRR,
сценарии, чувствительность, налоги РФ 2026 и экспорт отчётов в PDF/HTML.

**Демо:** после публикации на Streamlit Cloud — ссылка вида
`https://<логин>-washerbot-calculator-app-xxxx.streamlit.app`

## Что умеет

- **Простой режим** — быстрая оценка: окупаемость, NPV, IRR, прибыль/мес.
- **Углублённый режим** — полная модель: CAPEX/OPEX, кредит с графиком платежей,
  сезонность (пик ноябрь–май), внутрисуточный профиль (24/7, спад 01:00–06:00),
  пропускная способность и часовая загрузка, точка безубыточности.
- **Налоги 2026:** УСН 6 % с вычетом взносов (не более 50 %), НДС 22 % на ОСНО,
  порог НДС на УСН 20 млн ₽, ставки 5 % / 7 %, патент по регионам, взносы 30 %.
- **Вода и водоотведение:** тарифы по регионам, профили с платой за негативное
  воздействие и сверхнормативный сброс, оборотная вода.
- **Сценарии и сравнение** вариантов, матрица trade-off.
- **Экспорт:** инвестиционный отчёт (PDF/HTML), краткая версия, сравнение,
  помесячные CSV, ZIP-пакет для инвестора.

## Запуск локально

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Откроется <http://localhost:8501>.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest -q          # 166 тестов
```

## Публикация

Подробно — в [DEPLOY.md](DEPLOY.md): Streamlit Community Cloud (бесплатно),
Hugging Face Spaces, VPS с Docker и своим доменом.

Короткий путь: зайти на <https://share.streamlit.io>, выбрать этот репозиторий,
ветку `main`, файл `app.py` → Deploy.

## Структура

```
app.py            точка входа Streamlit
ui/               экраны, отчёты, экспорт PDF/HTML
finance/          налоги, тарифы, кредит, чувствительность
domain/           модели данных
data/             справочники (модели моек, регионы, программы)
tests/            pytest
assets/           логотипы
```

> Расчёты носят ориентировочный характер и не являются инвестиционной рекомендацией.
